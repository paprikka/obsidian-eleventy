## Observations:

The point still stands that most of my apps still fall into the categories of Indie, Walled Garden and Idiosyncratic/DYI:

[Embed](<../Default Apps 2023>){data-embed data-target="#^eff5ba"}


- I stopped using Penpot, mainly because I'm quite comfortable with sketching things in plain CSS + HTML. This is not a point agains Penpot – I'd ditch Figma, but my clients use it.
- I stopped using NeoVIM almost completely, but I kept the keyboard bindings and I'm pretty comfortable with modal editing now. 
- My main code editor is Cursor. We overestimate how useful AI is for complex stuff, but for quick repetitive edits, scaffolding or just sketching ideas – it works so well! 
- Apple Podcast UI was too annoying to use, so I gave in and switched to Overcast. I'm happy with it.
- It seems that I'm much more likely to both start reading and finish a book when it's an actual physical book, not Kindle.
- I'm still using the same utilities (Mail, Calendar). It's a marriage of convenience at this stage.
